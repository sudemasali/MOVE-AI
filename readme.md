# MoveAI - AI-Powered Sports Movement Analysis

MoveAI is an AI-powered sports movement analysis project developed using computer vision and machine learning techniques.

The project processes video data, extracts body landmarks and analyzes movement patterns.

---

## Features

- Video-based movement analysis
- Pose landmark extraction
- Skeleton data generation
- Feature extraction
- Machine learning model training
- Flask API integration

---

## Technologies Used

- Python
- Flask
- OpenCV
- MediaPipe
- Scikit-learn
- TensorFlow / Keras
- NumPy

## AI Pipeline

The project workflow includes:

1. Video processing
2. Pose estimation
3. Skeleton extraction
4. Feature extraction
5. Model training
6. Movement analysis

---

## Machine Learning

The project includes:

- Random Forest
- LSTM-based sequence modeling

---

## API

The system provides Flask-based API endpoints for movement analysis.


```bash
python src/api.py
```
